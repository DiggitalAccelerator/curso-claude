# Curso Claude Code — por Cristhian White

Aprende a construir tu sistema de IA personalizado en menos de una hora.
Todo el curso corre dentro de Claude Code. Sin videos. Sin plataformas externas.

---

## Instalación en 3 pasos

### 1. Instala Claude Code

```bash
npm install -g @anthropic-ai/claude-code
```

> Necesitas Node.js 18+ instalado. Si no lo tienes: [nodejs.org](https://nodejs.org)

### 2. Descarga el curso

Clona este repositorio o descarga el ZIP:

```bash
git clone https://github.com/DiggitalAccelerator/curso-claude.git
cd curso-claude
```

### 3. Instala y arranca

**macOS / Linux:**
```bash
bash install.sh
```

**Windows (PowerShell):**
```powershell
.\install.ps1
```

Luego abre Claude Code en cualquier carpeta de tu computadora y escribe:

```
/cw:start
```

## Lo que vas a construir

| Clase | Lo que haces |
|-------|-------------|
| `/cw:clase-1` | Le das memoria y personalidad a tu Claude con `CLAUDE.md` |
| `/cw:clase-2` | Construyes tu primera skill (comando personalizado) |
| `/cw:clase-3` | Lanzas múltiples Claudes en paralelo (subagentes) |
| `/cw:clase-4` | Conectas Claude con tus apps externas via MCP |
| `/cw:clase-5` | Construyes algo real para tu negocio y lo ves funcionar |
| `/cw:clase-6` | El sistema completo + qué sigue |
