# 10 Prompts Esenciales para tu Negocio

> Desbloqueado en la Clase 2 del Curso Claude Code — por Cristhian White
>
> **Cómo usar estos prompts:** Cópielos directamente en Claude Code. Funcionan mucho mejor si tienes tu `CLAUDE.md` configurado (Clase 1), porque Claude ya sabe quién eres y adapta el output automáticamente.

---

## CONTENIDO

### 1. Post para redes sociales desde una idea
```
Tengo esta idea para un post: [describe la idea en 1-2 líneas].

Escríbeme 3 versiones de post para Instagram:
- Versión 1: enfocada en el dolor/problema del lector
- Versión 2: enfocada en el resultado/transformación
- Versión 3: formato lista o pasos

Usa mi voz y el lenguaje de mi cliente ideal. Máximo 150 palabras cada una.
```

### 2. Hilo de Twitter/X desde contenido largo
```
Convierte este contenido en un hilo de Twitter de 6-8 tweets:

[pega el contenido]

Reglas:
- Tweet 1: hook que genere curiosidad o sorpresa
- Tweets 2-6: desarrollo con una idea por tweet
- Tweet final: CTA o reflexión de cierre
- Máximo 280 caracteres por tweet
```

### 3. Respuesta a un email difícil
```
Necesito responder este email de manera profesional pero firme:

[pega el email]

Contexto: [explica brevemente la situación]

Objetivo de mi respuesta: [qué quieres lograr]

Escríbeme 2 versiones: una más directa y una más diplomática.
```

## VENTAS Y CONVERSIÓN

### 4. Descripción de producto o servicio
```
Escríbeme la descripción de venta de [nombre del producto/servicio].

Lo que hace: [descripción funcional]
Para quién es: [perfil del cliente ideal]
Resultado principal que promete: [transformación o beneficio clave]

Formato: párrafo de apertura (gancho) + 3 bullets de beneficios + 1 frase de cierre con CTA.
Tono: [tu tono de voz]
```

### 5. Guión para video corto (Reel/TikTok)
```
Escríbeme un guión de 60 segundos para un video sobre [tema].

Estructura:
- Hook (0-3 seg): frase de apertura que detenga el scroll
- Problema (3-15 seg): el dolor que resuelve
- Solución (15-45 seg): el contenido de valor
- CTA (45-60 seg): qué hacer a continuación

Audiencia: [describe tu cliente ideal]
Tono: [tu tono]
```

### 6. Seguimiento a un lead sin sonar desesperado
```
Escribí a [nombre/lead] hace [X días] sobre [propuesta/oferta] y no respondió.

Escríbeme un mensaje de seguimiento de máximo 4 líneas que:
- No suene urgente ni desesperado
- Aporte algo de valor o contexto nuevo
- Tenga una pregunta de cierre que sea fácil de responder

Canal: [email / WhatsApp / DM]
```

## OPERACIONES

### 7. SOP de un proceso de tu negocio
```
Necesito documentar este proceso para que alguien en mi equipo pueda hacerlo:

Proceso: [nombre del proceso]
Lo que se hace actualmente: [descripción de cómo se hace paso a paso, aunque sea informal]

Convierte esto en un SOP (Procedimiento Operativo Estándar) con:
- Objetivo del proceso
- Quién lo ejecuta
- Pasos numerados con descripción clara
- Qué hacer si algo sale mal
```

### 8. Análisis rápido de métricas
```
Tengo estos números de [período]:

[pega los números o describe las métricas]

Analiza:
1. Qué está funcionando bien
2. Qué está bajando o preocupa
3. Las 3 acciones concretas que recomendarías hacer esta semana

Sé directo. No necesito contexto extenso, solo las conclusiones y acciones.
```

## ESTRATEGIA

### 9. Plan de contenido para 2 semanas
```
Crea un plan de contenido para las próximas 2 semanas para [plataforma principal].

Mi negocio: [descripción breve]
Mi audiencia: [cliente ideal]
Objetivo de este período: [ej: generar leads, posicionarme como experto, lanzar un producto]
Frecuencia de publicación: [X posts por semana]

Formato del plan: tabla con columna de día, tema, formato (post/carrusel/video/historia) y hook sugerido.
```

### 10. Revisión de una pieza de copy
```
Revisa este copy y dime cómo mejorarlo:

[pega el copy]

Qué quiero que hagas:
1. Identifica los 3 problemas principales
2. Señala dónde pierde fuerza o claridad
3. Reescribe los párrafos débiles

No cambies mi voz — mejora la estructura y claridad sin que suene a otra persona.
```
